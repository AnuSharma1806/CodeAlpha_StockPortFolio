CodeAlpha Stock Portfolio Tracker

📌 Project Description

This project is a simple Stock Portfolio Tracker developed using Python.

It allows the user to enter stock names and quantities and calculates the total investment value using predefined stock prices.

🛠️ Technologies Used

- Python
- Dictionary
- Input/Output
- While Loop
- If-Else
- Basic Arithmetic

📊 Features

- Enter stock name
- Enter quantity
- Display stock price
- Calculate investment for each stock
- Calculate total investment
- Handle invalid stock names

▶️ How to Run

1. Open the project in VS Code.
2. Open "stock_portfolio.py".
3. Run the Python file.
4. Enter the stock name and quantity.
5. Type "done" when you finish entering stocks.
